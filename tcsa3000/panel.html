Conectar una IA

TCSA3000 funciona con cualquier IA compatible con MCP. Las IAs web sin MCP usan el respaldo en Drive.

GitHub
TCSA3000 usa dos repositorios de GitHub, cada uno para una cosa:

 
  • Privado: copia completa de tu continuidad (proyectos, cierres, LISTA…). Es el segundo respaldo que leen las IAs si falla el MCP. Nadie más lo ve.
  • Público: solo las normas maestras y las instrucciones de los proyectos, para que cualquier IA pueda leerlas. Nunca se sube nada privado: si un fichero parece tener una clave, se bloquea.

 
Tercer respaldo: Google Drive
La continuidad vive aquí, en TCSA3000. Drive es una copia que se actualiza sola cada pocos minutos; nunca se borra nada en Drive, y lo que una IA web cree allí se trae aquí.
